## Sobre
Site de página única com tema escuro (gradiente teal→esmeralda), animações de scroll-reveal, contadores animados e formulário de contato. Apresenta trajetória, experiência, projetos, certificações e formação.

## Stack
- HTML5 + CSS3 (sem framework, sem build) — animações em CSS + IntersectionObserver
- Google Fonts (Space Mono · Outfit)
- Deploy na **Netlify** (DNS + HTTPS Let’s Encrypt); formulário via **Netlify Forms**

## Rodando localmente
Abra o `index.html` no navegador — todo o CSS e JS estão inline no arquivo.
